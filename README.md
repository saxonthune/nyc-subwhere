# nyc-subwhere
Live map of your favorite transportation network

Transit data from the [MTA](https://www.mta.info/developers). Independent project, not affiliated with or endorsed by the MTA.

Street grid © [OpenStreetMap](https://www.openstreetmap.org/copyright) contributors, licensed under the [ODbL](https://opendatacommons.org/licenses/odbl/), via a [BBBike](https://download.bbbike.org/osm/) extract. Citi Bike station data from the [Citi Bike system data](https://citibikenyc.com/system-data) feeds (Lyft). Borough boundaries from [NYC Open Data](https://opendata.cityofnewyork.us/).
